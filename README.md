# 本地资产：账单与资产管理

离线使用的 Android 记账应用，基于 [DykiSensei/seamless-bookkeeping](https://github.com/DykiSensei/seamless-bookkeeping) 修改，沿用 MIT 许可。应用本身不申请网络权限；核心账本保存在手机本地。

## 已实现

- 导入微信、支付宝原始 CSV / XLSX 账单，以及建设银行文字版交易明细 PDF。先预览笔数、金额、异常行和疑似重复，确认后整批写入；可撤销最近一批导入。
- 同单号自动跳过。银行和支付平台可能记录同一消费，账单页提供相似流水提示，由用户确认关联，统计只算一次。不会仅凭金额自动合并。
- 手动记录银行卡、支付宝余额、微信零钱和每只基金市值。余额校准有时间和原因记录；基金市值仍由用户手动更新。
- 账户转账同时更新两个已管理账户，手续费单独记支出。银行卡申购基金可以只扣银行卡，基金市值由用户另行校准。
- 退款、报销可关联原支出，支持部分到账；它们抵减原消费，不作为普通收入。未关联的退款会提示待核对。
- 可恢复删除流水和账户归档。预算、统计、分类明细、手动及语音输入仍可使用。
- 设置页可导出和恢复带口令的本地加密备份。备份包含账户、流水、导入记录、余额校准、待确认通知和预算。请保存口令，忘记后无法恢复。
- 通知辅助记账默认关闭。开启并由系统授予通知使用权后，只读取受支持的支付通知，生成待确认草稿；确认前不写入正式账本。短信和无障碍自动抓取未启用。

## 构建与安装

准备 JDK 21、Android SDK 35。在 Windows 纯英文路径运行：

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。安装和升级步骤见 [K80 Pro 安装与使用说明](K80Pro-安装与使用.md)。调试包签名可能与手机已安装版本不同；提示签名不一致时先保留旧版和数据，不要卸载旧版强装。

## 使用边界

建设银行 PDF 只支持已识别的文字版固定表格，扫描图片版和其他银行格式暂不支持。PDF 原单若只有日期，交易按当天 00:00 处理；与同日手动余额起点重合的交易不会自动改余额。

支付宝、微信账单只有明确写出余额或零钱付款方式时才更新对应余额；银行卡余额只由银行 PDF 更新。通知草稿需要人工核对金额、账户和重复情况。语音输入由手机安装的识别服务处理，服务是否联网取决于手机设置。

本地数据库目前未加密；加密的是用户手动导出的备份。请保护手机解锁方式，不要把备份口令与备份文件放在一起。真机上的通知投递、跨版本覆盖安装和实际余额对账仍需在目标手机验证。
