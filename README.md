# 本地资产：账单与资产管理

离线使用的 Android 记账应用，基于 [DykiSensei/seamless-bookkeeping](https://github.com/DykiSensei/seamless-bookkeeping) 修改，沿用 MIT 许可。应用本身不申请网络权限；核心账本保存在手机本地。

## 已实现

- 导入微信、支付宝原始 CSV / XLSX 账单，以及建设银行文字版交易明细 PDF。先预览笔数、金额、异常行和疑似重复，确认后整批写入；可按导入批次撤销及恢复。
- 同单号自动跳过。银行和支付平台可能记录同一消费，账单页提供相似流水提示，由用户确认关联，统计只算一次。不会仅凭金额自动合并。
- 手动记录银行卡、支付宝余额、微信零钱和每只基金市值。余额校准有时间和原因记录；基金市值仍由用户手动更新。
- 账户转账同时更新两个已管理账户，手续费单独记支出。银行卡申购基金可以只扣银行卡，基金市值由用户另行校准。
- 退款、报销可关联原支出，支持部分到账；它们抵减原消费，不作为普通收入。未关联的退款会提示待核对。
- 账单支持月份选择、关键词搜索及账户、来源、金额、类型组合筛选；可以补记真实交易日期。删除流水和归档账户都有长期恢复入口。
- 统计分类支持金额升序/降序、进入分类查看流水，并从详情编辑原交易。净消费扣除已关联退款/报销，原支付额与净额分别展示。
- 月预算模板与流水使用同一数据库备份和恢复。预算可查看不同月份；模板修改会用于所查看月份，不保存各月历史预算版本。
- 常用账户需要用户明确选择；记账保留最近分类。保存失败保留表单，重复提交使用同一个表单标识。
- 通知草稿按同内容分组，确认前重新核对相似流水；已忽略或判重的通知可在处理历史中找回。
- 设置页提供截图保护和基于手机锁屏凭据的应用锁。
- 设置页可导出和恢复带口令的本地加密备份。备份包含账户、流水、导入记录、余额校准、待确认通知和预算。请保存口令，忘记后无法恢复。
- 通知辅助记账默认关闭。开启并由系统授予通知使用权后，只读取受支持的支付通知，生成待确认草稿；确认前不写入正式账本。短信和无障碍自动抓取未启用。

## 构建与安装

最低 Android 8.0（API 26）。准备 JDK 21、Android SDK 35。在 Windows 纯英文路径运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。安装和升级步骤见 [K80 Pro 安装与使用说明](K80Pro-安装与使用.md)。本次交付调试包已比对本地 v1.13 签名一致；其他电脑重新构建的调试包签名可能不同。提示签名不一致时先保留旧版和数据，不要卸载旧版强装。

界面配色、排版、金额显示和各页面规则见 [UI 设计规范](UI-设计规范.md)。设置页可选浅色、深色或跟随系统；资产页可临时隐藏金额。

## 使用边界

建设银行 PDF 只支持已识别的文字版固定表格，扫描图片版和其他银行格式暂不支持。PDF 原单若只有日期，交易按当天 00:00 处理；与同日手动余额起点重合的交易不会自动改余额。

支付宝、微信账单只有明确写出余额或零钱付款方式时才更新对应余额；银行卡余额只由银行 PDF 更新。通知草稿需要人工核对金额、账户和重复情况。语音输入由手机安装的识别服务处理，服务是否联网取决于手机设置。

本地数据库目前未加密；加密的是用户导出的备份及恢复前安全副本。应用锁不等于数据库加密。请保护手机解锁方式，不要把备份口令与备份文件放在一起。真机上的通知投递、跨版本覆盖安装和实际余额对账仍需在目标手机验证。
