# 本地资产 1.14.2 测试版

发布日期：2026-10-25。versionCode 17，数据库 v7，最低 Android 8.0。

本包面向安卓通用设备，不限红米；包含 arm64-v8a、armeabi-v7a、x86、x86_64。不同品牌的通知、语音和后台限制仍需要实测。

## 更新

- 修复主动删除的流水重新导入后被自动恢复、再次影响余额的问题。重导保留删除状态和原导入批次，需要用户显式恢复。
- 为新建重复关联保存退款归属的撤销记录；解除关联时校验并还原。后续修改或依赖可能影响正确还原时，保留账本并提示核对。
- 新增 v6→v7 迁移，仅增加撤销记录表；统计公式和金额存储口径保持一致。
- 加密备份升级为 format 3，包含撤销记录；仍可读取旧版 format 1/2 备份。

## 下载及升级

安装文件：`local-assets-v1.14.2-debug.apk`。同目录提供 SHA256SUMS.txt。

先在旧版导出一份外部加密备份并保留口令，再直接覆盖安装。不要先卸载旧版。安装包沿用已交付 1.14.1 的证书，以维持覆盖升级；当前仍为调试签名测试包。

升级后数据库为 v7，不支持直接回退到 v6。新版导出的 format 3 备份不能交给 1.14.1 读取；请保留升级前的旧版备份。

## 验证及限制

账务修复覆盖 87 项回归测试，审计、复现及迁移证据见 docs/audits/。本轮发布构建的结果和安装包哈希见《交付校验-1.14.2.md》。GitHub CI 编译包使用其独立调试证书，不能替代本次上传的覆盖升级包。

未完成真机 v6 副本升级和真实历史账单逐笔对账，本次作为测试版发布。旧版已丢失的退款归属不能自动还原；旧关联可能需要人工核对。不会批量修改已有用户账本来推断旧归属。

应用数据保存在手机本地，本地数据库尚未加密；备份和恢复前安全副本使用口令加密。
